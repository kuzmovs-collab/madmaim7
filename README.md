# Фото счётчиков — стартовый проект Android (v1.1)

## Функционал
1. Съёмка фото счётчика через CameraX
2. Автосъёмка: снимок делается сам при распознавании штрихкода/QR (переключается в настройках)
3. Распознавание штрихкода/QR в реальном времени (ML Kit, офлайн)
4. Запасной вариант: распознавание печатного номера с готового фото (кнопка «Распознать с фото»)
5. Подтверждение/правка номера перед сохранением
6. Файл сохраняется как `номер_счётчика.jpg`
7. Очередь отправки: фото отправляется автоматически при появлении интернета,
   WorkManager повторяет попытки и переживает перезагрузку телефона
8. Экран настроек: адрес получателя, отправитель, SMTP, автосъёмка

## Структура
- `MainActivity.kt` — камера, съёмка, диалог подтверждения, постановка в очередь
- `BarcodeAnalyzer.kt` — распознавание штрихкодов в видеопотоке
- `TextNumberRecognizer.kt` — OCR печатного номера с фото
- `PhotoStorage.kt` — переименование и сохранение файла
- `OutboxStore.kt` — очередь несохранённых отправок (JSON)
- `SendWorker.kt` — фоновая отправка с автоповтором (WorkManager)
- `MailSender.kt` — отправка письма с вложением через SMTP
- `SettingsActivity.kt` + `SettingsStore.kt` — настройки

## Сценарий работы в поле
1. Навели камеру на наклейку → номер распознан → снимок сделан автоматически
2. Проверили номер, при необходимости нажали «Распознать с фото»
3. «Сохранить и отправить» → фото в очереди
4. Нет интернета в подвале — не страшно: отправится, когда сеть появится
